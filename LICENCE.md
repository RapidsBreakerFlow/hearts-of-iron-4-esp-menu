## 🛠 Troubleshooting

**Menu does not appear:**  
- Ensure the game is running in windowed or borderless mode.
- Run the tool as Administrator.
- Check that your antivirus is not blocking the overlay.

**ESP not showing:**  
- Verify `process_name` is set to `hoi4.exe`.
- Restart both the game and the tool.
- Update to the latest version.

**Game crashes on startup:**  
- Disable other mods that may conflict.
- Reinstall the tool from the official source.
- Check for game updates.
